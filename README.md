# Automotive Landing Page Clone (Frontend Study)

A fully responsive, custom-coded implementation of a modern luxury automotive digital layout. 

## 💡 Project Purpose
This repository is a **frontend development exercise** created strictly for educational and portfolio practice. The primary goal of this project was to practice "Design-to-Code" translation—taking a high-fidelity visual mockup and reverse-engineering it into clean, semantic, and highly responsive HTML, CSS, and JavaScript.

## 🛠️ Tech Stack
* **HTML5** (Semantic layout architecture)
* **CSS3** (Flexbox, Grid, and responsive media queries)
* **Vanilla JavaScript** (Interactions and animations)
